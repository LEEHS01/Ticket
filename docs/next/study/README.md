# 미리내 마당 코드 구조 정리

티켓 예매 프로그램이 코드로 어떻게 만들어져 있는지, 처음 보는 사람도 순서대로 읽을 수 있게 열 장으로 나눴다. 기준은 `next` 브랜치의 2026-11-26 상태다.

GitHub에서 열면 그림이 그려진다. 그림의 원본은 각 장의 코드 블록(mermaid)이다.

## 차례

| 장 | 내용 |
|---|---|
| [1. 한눈에 보기](01-start.md) | 이 프로그램이 무엇이고, 어떤 순서로 읽으면 되는지부터 본다. |
| [2. 무엇을 하나](02-features.md) | 기능 명세다. 누가 무엇을 할 수 있고, 어떤 규칙이 걸려 있는지 본다. |
| [3. 예매가 되는 과정](03-booking.md) | 예매하기를 누른 뒤 일어나는 일을 네 단계로 따라간다. 단계마다 풀어야 할 문제가 하나씩 있다. |
| [4. 로그인](04-login.md) | 서버가 '이 요청은 누가 보낸 것인가'를 어떻게 아는지 본다. |
| [5. 데이터](05-data.md) | 어떤 데이터가 어느 저장소에 어떤 모양으로 있고, 화면까지 어떻게 오는지 본다. |
| [6. 백엔드 코드](06-backend.md) | 서버 코드가 어떤 덩어리로 나뉘어 있고, 요청 하나가 그 사이를 어떻게 지나는지 본다. Java 21과 Spring Boot 3으로 썼다. |
| [7. 프론트엔드 코드](07-frontend.md) | 화면 코드가 어떻게 나뉘어 있고, 서버에서 받은 데이터를 어떻게 다루는지 본다. TypeScript와 React로 썼다. |
| [8. 아키텍처 패턴](08-arch-patterns.md) | 아키텍처 패턴은 프로그램 전체를 어떤 덩어리로 나누고 어떻게 잇는가에 대한 것이다. 이 프로그램이 고른 것과 고르지 않은 것을 본다. |
| [9. 디자인 패턴](09-design-patterns.md) | 디자인 패턴은 클래스 몇 개를 어떤 모양으로 짜는가에 대한 것이다. 이 코드에 실제로 쓰인 것을 종류별로 본다. |
| [10. 코드 읽는 순서](10-reading.md) | 실제 파일을 열어 볼 때의 순서다. 예매 한 건을 따라가며 읽으면 앞 장의 내용이 코드에서 그대로 보인다. |

프로그램이 무엇을 하는지만 궁금하면 2장과 3장만 읽어도 된다. 어떤 패턴으로 짰는지는 8장(프로그램 전체의 뼈대)과 9장(클래스 단위의 모양)에 있다.
