그리지 않은 것과 계획으로 표시한 것

  • 그림 2의 EKS 쪽은 전부 계획입니다. 매니페스트, ECR 저장소, RDS, ElastiCache, Ingress는 아직 만들지 않았습니다.
  • 노드 수, 인스턴스 크기, VPC·서브넷 CIDR, 가용 영역, HPA 기준값(CPU % 등)은 프로젝트 파일에 없어서 그리지 않았습니다.
  • ECR은 프로젝트 파일에는 아직 나오지 않고 배포 계획에서 가져왔습니다. ElastiCache와 클러스터 내부 Redis 중 무엇을 쓸지도 아직 정하지 않았습니다.
  • 프론트엔드 이미지 크기와 기동 시간은 README에 측정값이 없어 적지 않았습니다.
  • compose 파일의 개발용 비밀번호 값은 이 페이지에 넣지 않았습니다.
